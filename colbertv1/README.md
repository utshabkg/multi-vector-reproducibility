# ColBERT-v1 (Supplementary)

This directory contains exploratory ColBERT-v1 experiments using PyTerrier. These results are **not referenced in the paper** and are included only as supplementary material for completeness.

ColBERT-v1 was evaluated via PyTerrier's ColBERT integration to provide additional context on the evolution of multi-vector retrieval models.

## Results

- `results/pyterrier_colbertV1_msmarco-passage_eval.json` — MS MARCO evaluation
- `results/pyterrier_colbertV1_tot_dev*_eval.json` — TREC ToT dev split evaluations
- `results/pyterrier_colbert1.9_msmarco_eval.json` — ColBERT v1.9 MS MARCO evaluation
